# เพิ่มตัวละครใหม่

ตัวละครแต่ละตัวอยู่ในโฟลเดอร์ของตัวเอง ทุกอย่างของตัวละครอยู่ในไฟล์เดียวคือ `character.js`
ได้แก่ รูป sprite, ค่าพลัง, คอมโบ และสกิลพร้อมเอฟเฟกต์ ส่วนตัวเกม (`game.js`) ไม่ต้องแก้

```
web/characters/
  kan/                 ตัวอย่างที่ใช้งานจริง (กัลป์ เกรียงไกร)
    character.js
    sprites/*.png
  _template/           ต้นแบบสำหรับตัวใหม่
```

## ขั้นตอน

1. สร้างโฟลเดอร์จากต้นแบบ:

   ```
   python3 tools/new_character.py saen "แสน ราชสีห์" "SAEN RACHASI" --placeholder-sprites
   ```

   - สร้าง `web/characters/saen/` และเพิ่ม `<script>` ใน `web/index.html` ให้อัตโนมัติ
   - `--placeholder-sprites` คัดลอกรูปของกัลป์มาใส่ไว้ก่อน เกมจึงเล่นได้ทันที แล้วค่อยเปลี่ยนรูปทีละไฟล์
   - เปิด `web/index.html#saen` เพื่อเล่นตัวใหม่ (ไม่ใส่ `#` จะเป็นกัลป์)
2. ทำรูปตัวละครตามตารางด้านล่าง แล้ววางใน `sprites/`
3. แก้ชื่อ ค่าพลัง ดาเมจ และสกิลใน `character.js`
4. รัน `python3 tools/build_sw.py` ให้ไฟล์ใหม่เข้าแคชของแอป (PWA เล่นออฟไลน์ได้)

## รูปที่ต้องมี

ทุกรูปเป็นแถบแนวนอน เฟรมละ **224×224 px** พื้นหลังโปร่งใส ตัวละคร**หันขวา**
ให้เท้าอยู่ที่จุด (95, 220) ของทุกเฟรม (ตั้งค่าได้ที่ `sprite.anchorX/anchorY`)
จำนวนเฟรมนับจากความกว้างรูปเอง

| ไฟล์ | เฟรม | ใช้ทำอะไร |
|---|---|---|
| `portrait.png` | 1 | รูปหน้าใน HUD (กำหนดส่วนที่ตัดด้วย `portrait.crop`) |
| `idle.png` | 8 | ท่ายืน วนซ้ำ |
| `walk.png` | 8 | เดิน วนซ้ำ |
| `jump.png` | 8 | กระโดด เฟรม 2–6 เป็นช่วงลอยตัว (`airFrames`) |
| `attack1–5.png` | 4 ต่อท่า | คอมโบบนพื้น: ง้าง → ขยับ → ขยับ → ตี |
| `air1–3.png` | 4 ต่อท่า | คอมโบกลางอากาศ ท่าที่ 3 คือฟาดดิ่งลงพื้น |
| `sk_<id>.png` | 3 ต่อท่า | สกิล 1 ไฟล์ต่อ 1 สกิล |

### ทำรูปด้วย PixelLab

1. ทำรูปยืนหันขวาหนึ่งรูป (เช่น `create_image_pro` หรือ `image_to_pixelart` จากรูปถ่าย)
   แล้ววางบนผืน 224×224 ให้เท้าอยู่ที่ (95, 220)
2. ใช้รูปนั้นเป็นเฟรมแรกของ `animate_image_pixminimax`
   (`view: "side"`, `direction: "east"`) แล้วบอกท่าทีละท่า เช่น
   - เดิน: `walking forward in a guarded stance, looping walk cycle, stays in place` (8 เฟรม)
   - ตีคอมโบ: `4 frames: (1) wind-up ... (2) ... (3) ... (4) strike ...` (4 เฟรม)
   - ระบุ "RIGHT hand only" หรืออาวุธที่ใช้ให้ชัดทุกครั้ง
3. ดึงเฟรมมาเป็นแถบ:

   ```
   python3 tools/fetch_anim.py <job_id> web/characters/saen/sprites/walk.png --skip-first
   ```

   `--skip-first` ตัดเฟรมแรกที่เป็นรูปต้นแบบออก
4. สกิลเอา 3 เฟรมจากที่สร้างมา 4 เฟรม:

   ```
   python3 tools/pack_skill.py <แถบ 4 เฟรม>.png web/characters/saen/sprites/sk_xxx.png 0 2 3
   ```

   ถ้ามีชิ้นส่วนหลุดลอยในเฟรม (เช่น อาวุธที่ขว้างออกไป) ใส่ `--keep-largest=<ลำดับเฟรม>` เพื่อลบออก

## เอฟเฟกต์ (VFX)

เอฟเฟกต์ใช้ร่วมกันทุกตัวละคร อยู่ที่ `web/assets/vfx_<key>.png` มี `bird, naga, chakra, tiger, rocks, yama, storm`

ถ้าจะเพิ่มเอฟเฟกต์ใหม่:

1. สร้างรูปด้วย `create_image_pro` (พื้นหลังโปร่งใส) แล้วบันทึกเป็น `web/assets/vfx_<key>.png`
2. ถ้าต้องการให้ขยับเป็นเฟรม ใช้ `animate_image_pixminimax` แล้วรัน
   `python3 tools/fetch_vfx.py <job_id> <key>`
3. เพิ่ม key ใน `VFX` (และ `VFX_ANIM` ถ้ามีแอนิเมชัน) ใน `tools/build_manifest.py`
   แล้วรัน `python3 tools/build_manifest.py`

## ค่าใน character.js

**ตัวละคร**: `name`, `hudName`, `hp`, `walkSpeed`, `jumpVelocity`, `sfx`, `sprite`, `portrait` (ในโหมดต่อสู้ HP เริ่มที่ 800 เท่ากันทุกตัว ค่า `hp` ไม่ถูกใช้)

**เสียง (`sfx`)**: เสียงตอนตีโดน `"stick"` = ไม้กระทบดังแป๊ก หรือ `"fist"` = หมัดกระแทกเนื้อ (แถวคอมโบที่มี `punch: true` ใช้เสียงหมัดเสมอ) เสียงทั้งหมดสังเคราะห์ใน `web/sfx.js` ไม่ต้องมีไฟล์เสียง

**แอนิเมชัน (`anims`)**
- `fps` + `loop`: ท่าที่วนซ้ำ
- `duration`: ความยาวท่า (วินาที)
- `playFor`: เล่นเฟรมให้จบภายในสัดส่วนนี้ของ `duration` แล้วค้างเฟรมสุดท้าย
- `hitAt`: จังหวะที่โดน (สัดส่วนของ `duration`)
- `anchorY`: ระดับเท้าเฉพาะท่านี้
- `bottoms: "auto"`: ให้เกมหาระดับเท้าเองทุกเฟรม ใช้กับท่าที่ตัวขยับขึ้นลงในเฟรม เช่น กระโดด

**คอมโบ (`combo`, `airCombo`)**: 1 แถวต่อ 1 ฮิต มีกี่ฮิตก็ได้
- `dmg: [ต่ำสุด, สูงสุด]`, `crit` (โอกาสคริติคอล), `kb` (แรงผลัก), `reach` (ระยะ px)
- `dir`: ทิศฟัน (`1` ซ้าย→ขวา, `-1` ขวา→ซ้าย)
- `power`: `0` ปกติ, `1` แรง, `2` ปิดท้าย (รอยฟันใหญ่ จอสั่น)
- `drift`: ไถลไปข้างหน้า
- `spin`: รอยฟันเป็นวงรอบตัว
- `plunge`: ฟาดดิ่ง (ใช้ในคอมโบกลางอากาศ)

**สกิล (`skills`)**: ก่อนเริ่มต่อสู้ผู้เล่นเลือกสกิลธรรมดา 2 ท่า + ไม้ตาย (`ult: true`) 1 ท่า จึงต้องมีสกิลธรรมดาอย่างน้อย 2 ท่าและไม้ตายอย่างน้อย 1 ท่า
- `name`, `desc`, `cd` (คูลดาวน์), `ult` (ไม้ตาย: ฉากมืด ปุ่มขอบแดง)
- `icon`: key ของเอฟเฟกต์ที่ใช้เป็นรูปปุ่ม
- `dur` + `frames: [เริ่มเฟรม1, เฟรม2, เฟรม3]` (สัดส่วนของ `dur`), `loopFrames`: วน 3 เฟรมเร็ว ๆ (ท่าหมุน)
- `assist`: ถ้าศัตรูอยู่ไกลกว่าระยะนี้นิดหน่อย จะพุ่งเข้าไปเอง
- `drift`: เคลื่อนไปข้างหน้าขณะใช้
- `hits: [{ at, dmg, reach, power, both, knockdown, stun, fx }]`
  - `both`: โดนทั้งหน้าและหลัง
  - `knockdown`: ทำให้ล้ม (วินาที)
  - `stun`: ทำให้มึน (วินาที)
- `aura`: เอฟเฟกต์ที่ติดตัวตลอดท่า (เช่น พายุ)
- `shot: { at, fx, dmg, range, speed }`: ขว้างของออกไปแล้ววนกลับเข้ามือ
- `leap: true` + `hit`: กระโดดแล้วฟาดพื้น ฮิตเกิดตอนลงถึงพื้น

**เอฟเฟกต์ของฮิต (`fx`)**: รายการเอฟเฟกต์ที่ออกตอนโดน
- `key`: ชื่อเอฟเฟกต์
- `dx`, `dy`: ระยะเลื่อน (บวก = ไปทางที่หัน)
- `at`: `"body"` ระดับอก หรือ `"ground"` ระดับพื้น
- `vx`, `vy`: ความเร็ว
- `life`: อายุ (วินาที)
- `s0`, `s1`: ขนาดตอนเริ่มและตอนจบ
- `rot`: หมุนภาพ
- `anchor`: `"center"`, `"left"` หรือ `"bottom"`
- `stretch`: ยืดตามแนวนอน (ไฟพ่น)
- `shockwave`: คลื่นกระแทกที่พื้น
- `sparks: [[จำนวน, "สี"], ...]`: ประกายไฟ

**ชุดสกิล**: `skillOrder` คือลำดับในหน้าเลือกสกิล และ `defaultLoadout` คือชุดเริ่มต้น (ธรรมดา 2 + ไม้ตาย 1)
